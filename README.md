# SDP Integration Prototype


## Requirements
* Docker
* Python 3.4 or later
* DockerPy
* netifaces
* pyroute2
* rpyc
* zmq
* pyftpdlib

## Notes
* pyroute2 is Linux only (https://github.com/svinota/pyroute2/issues/261)
